# Sales HQ — бэкенд

FastAPI + SQLAlchemy 2.0 (async, asyncpg) + Alembic + Pydantic v2. Контракт API — в
`../docs/api-contract.md`, он первичен.

## Запуск для разработки

```bash
docker compose -f ../docker-compose.dev.yml up -d      # Postgres на 5432
uv sync
uv run alembic upgrade head
uv run uvicorn app.main:app --reload --port 8000        # DEBUG=true включает /api/docs
```

Переменные окружения читаются из `.env` в этой папке или из окружения (см. `../.env.example`).

## Тесты

Тесты ходят в настоящий Postgres: составные FK и JSONB на SQLite не проверить.
Схема накатывается миграциями, поэтому тесты заодно проверяют Alembic.

```bash
docker run -d --name crm-test-pg -e POSTGRES_USER=crm -e POSTGRES_PASSWORD=crm \
  -e POSTGRES_DB=crm_test -p 5433:5432 postgres:16-alpine
TEST_DATABASE_URL=postgresql+asyncpg://crm:crm@localhost:5433/crm_test uv run pytest
uv run ruff check . && uv run ruff format --check .
```

## Устройство

```

├── core/       config (pydantic-settings), db (engine, Base), security (argon2, токены), deps (сессия, роли)
├── models/     одна таблица — один класс; все доменные таблицы с org_id и составными FK

├── api/        common.py (get_or_404, ensure_exists) и routers/ по доменам
└── services/   mail, tokens (инвайт/сброс), onboarding (сборка Me), pipeline, demo

```

### Изоляция тенантов

- У каждой доменной таблицы `org_id` и уникальный ключ `(org_id, id)`.
- Ссылки между сущностями — составные FK `(org_id, X_id) → (org_id, id)`. Сделка физически не
  может указывать на стадию, контакт или пользователя другой организации.
- Каждый запрос фильтруется по `org_id` текущего пользователя (`get_or_404`); чужой объект
  неотличим от несуществующего. Ссылки в теле запроса проверяются `ensure_exists` → 422.
- Побочный эффект составных FK: `ON DELETE SET NULL` обнулил бы и `org_id`, поэтому
  обнуление ссылок (удаление контакта, сделки) делается в коде, а не в схеме.

### Сессии и токены

- Cookie `session` — случайный токен, в БД sha256. Срок 30 дней, продлевается при
  активности не чаще раза в день. `Secure`, если `APP_URL` начинается с `https://`.
- Приглашения (14 дней) и сброс пароля (2 часа) — одноразовые токены, тоже sha256.
  Выдача нового гасит прежний. Сброс пароля удаляет все сессии пользователя.
- Отключение пользователя удаляет его сессии сразу.

## Решения

Места, где контракт молчал или упирался в реальность:

- **Email глобально уникален** (один человек — одна организация). Поэтому демо-коллеги
  получают адрес вида `d.volkov+demo-<8 символов id организации>@saleshq.ru`, а не просто
  `+demo`: иначе вторая организация не смогла бы загрузить демо.
- **Демо в пустой воронке.** Если открытых стадий нет, все демо-сделки ложатся на
  закрывающую, и открытые получают исход `won` — на закрывающей стадии сделка без исхода
  невалидна.
- **Очистка демо** удаляет и настоящие записи, жёстко привязанные к демо-клиентам
  (сделки и контакты демо-компаний, активности по ним): без компании они невалидны.
  Необязательные ссылки (контакт у сделки, сделка у активности) обнуляются. Настоящие
  записи, где демо-коллега стоял ответственным, переводятся на текущего пользователя.
- **Демо-коллегу нельзя удалить** через `DELETE /api/users/{id}` (409): он владеет
  демо-сделками, убирается вместе с демо-данными.
- **Приглашённого нельзя отключить** (409) — приглашение отменяется `DELETE`.
- **Порядок стадий**: `POST /api/stages` вставляет перед закрывающей; `PUT /order` принимает
  полный список и принудительно ставит закрывающую последней (даже если клиент прислал иначе).
- `openapi.json` доступен всегда (фронтенд генерирует из него типы), `/api/docs` — только при
  `DEBUG=true`.
- `amount` — `Numeric(14,2)` в БД, на проводе `number`.
- `createdAt` у сделки — бизнес-дата `YYYY-MM-DD` (колонка `created_on`), отдельно от
  технической метки `created_at`.
- Ответ `/api/auth/forgot-password` всегда 204, письмо уходит только при настроенном SMTP.
  Без SMTP админ выдаёт ссылку через `POST /api/users/{id}/reset-link`.
- Дата «сегодня» на сервере — UTC-дата (`date.today()` контейнера). Фронтенд считает
  «сегодня» по браузеру.
