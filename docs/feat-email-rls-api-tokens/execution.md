## Прод
- Хостинг закрывает исходящие порты 587 и 465, открыт 443, поэтому почта идёт через HTTPS API Postbox.
- API-ключ Postbox для HTTPS не подходит (403); пользователь добавил на сервер статический ключ.
- Запрос со статическим ключом проходит авторизацию; Postbox отвечает `MailFromDomainNotVerifiedException`: домен `sdelka.app` в Postbox не подтверждён. Это действие в консоли Yandex Cloud и в DNS, агенту недоступно.
