Принято: запрос пользователя в разговоре 2026-11-21 и его уточнения (Postbox, full-send, доведение прода до рабочего состояния).

## Что нужно
- Письма: подтверждение почты при регистрации, сброс пароля и сопутствующие уведомления. Отправка через Yandex Cloud Postbox.
- Мультитенантность: общие таблицы и RLS.
- API с авторизацией по токену; токен пользователь выпускает на странице профиля.
- Выкатить на прод и убедиться, что он работает.

## Критерии
- Без подтверждения почты новый аккаунт не входит, если почта настроена; без почты регистрация работает как раньше.
- База не отдаёт и не принимает строки чужой организации, даже если в запросе нет фильтра по `org_id`.
- Запрос с `Authorization: Bearer sdl_…` работает с правами и организацией владельца токена.
- Существующие пользователи прода входят после миграции.
