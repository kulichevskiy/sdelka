# Ревью

Независимый проход отдельным агентом по незакоммиченному дереву ветки, 2026-11-21. Статический: тесты агент не запускал.

| № | Находка | Решение |
|---|---|---|
| 1 | API-токен админа мог получить ссылку сброса пароля или приглашения и превратиться в браузерную сессию | Исправлено: изменения в `/api/users` доступны только из браузерной сессии, тест `test_token_cannot_manage_people` |
| 2 | В `.env.example` остались строки старого комментария без `#` | Исправлено |
| 3 | Смена пароля в настройках не завершает другие сессии и не отзывает токены | Оставлено: в спецификации отзыв только при сбросе и отключении |
| 4 | Ссылка подтверждения почты переживала сброс пароля | Исправлено: сброс гасит ссылки подтверждения, тест дополнен |
| 5 | Для SMTP-портов, кроме 587 и 465, поменялось поведение STARTTLS | Исправлено: возвращено прежнее |
| 6 | `/api/docs` открыт всегда | Оставлено: решение из спецификации |
| 7 | Страница подтверждения не чистила кэш прежнего аккаунта | Исправлено |

Вне задачи: админ и раньше мог выпустить ссылку сброса пароля для владельца (`reset-link` не вызывает `_check_can_manage`). Поведение существовало до ветки и не менялось.

Проверено и признано корректным: политики RLS и права роли, область транзакции и пул соединений, `get_current`, системные эндпоинты, фильтр токенов по пользователю, сценарии подтверждения почты, миграция на живых данных, подпись SigV4.
