## Решения агента
- **RLS без нового пользователя БД.** Миграция `0002` создаёт роль `sdelka_app` без входа. Приложение подключается прежним пользователем и в каждой транзакции переключается на эту роль и задаёт `app.org_id`. Сессия без организации не видит строк. Код до аутентификации работает через системную сессию в обход RLS.
- **Фильтры по `org_id` в коде остаются** вторым рубежом.
- **Подтверждение почты** требуется только при настроенной почте. Существующие пользователи с паролем считаются подтверждёнными. Принятие приглашения и сброс по ссылке из письма подтверждают почту.
- **Postbox по HTTPS.** Хостинг прода закрывает исходящие порты 587 и 465, поэтому при заданных `POSTBOX_KEY_ID` и `POSTBOX_SECRET_KEY` письма уходят через HTTPS API с подписью AWS Signature V4. SMTP остаётся запасным вариантом.
- **API-токены** бессрочные, до 20 на пользователя, в БД хранится sha256. Управлять токенами и менять пароль можно только из браузерной сессии. Сброс пароля и отключение пользователя удаляют его токены.
- **`/api/docs` открыт всегда** как документация API.
